# Marine Detail Supply Global Theme Framework

## Summary
Enterprise Shopify multi-store theme system built on Taillour Boilerplate Theme. Production-ready framework powering the Marine Detail Supply franchise network with custom Tailwind CSS, Vite build pipeline, ESM modules, and Docker containerization. Designed for long-term maintenance, global updates, and multi-store deployments.

## Structure
**Main Directories**:
- **`src/`** - Source files (uncompiled JavaScript and CSS)
  - `scripts/` - JavaScript modules, components, and core utilities
  - `styles/` - Tailwind CSS configuration and custom design system
- **`assets/`** - Compiled output (generated by Vite)
- **`layout/`** - Shopify layout templates (theme.liquid, password.liquid)
- **`templates/`** - Shopify JSON templates (product, collection, cart, etc.)
- **`sections/`** - Shopify sections (header, footer, product grids, etc.)
- **`snippets/`** - Reusable Liquid snippets
- **`config/`** - Theme configuration and multi-store settings
  - `stores/` - Per-store configurations and overrides
- **`scripts/`** - Build and deployment scripts
  - `docker/` - Docker helper scripts (dev.sh, vite.sh, build.sh, deploy.sh)
- **`docs/`** - Comprehensive documentation (development, deployment, multi-store, Docker)

**Architecture**: Multi-store framework with per-store overrides. Uses Web Components for interactive features, Vite for build pipeline, and Shopify Liquid for templating.

## Language & Runtime
**Language**: JavaScript (ES Modules)  
**Version**: Node.js 20.x (Bullseye Slim)  
**Build System**: Vite 5.x  
**Package Manager**: npm  
**Shopify CLI**: 3.x (Ruby-based, installed in Docker container)

## Build & Installation
```bash
# Clone and install
git clone <repository-url>
cd mdsc-shopify-theme
npm install

# Configure environment
cp .env.example .env
# Edit .env with Shopify store details

# Local development
npm run dev              # Start Vite dev server with HMR
npm run build            # Build production assets
npm run watch            # Build and watch for changes
npm run shopify:dev      # Start Shopify CLI dev server
npm run shopify:push     # Push theme to store
npm run shopify:check    # Run theme validation

# Multi-store deployment
npm run deploy -- --store=headquarters    # Deploy to specific store
npm run deploy -- --all                   # Deploy to all stores

# Docker development (recommended)
./scripts/docker/vite.sh     # Start Vite dev server (port 3000)
./scripts/docker/dev.sh      # Start Shopify theme preview (port 9292)
./scripts/docker/build.sh    # Build production assets
./scripts/docker/deploy.sh --store=store-name    # Deploy to store
```

## Docker
**Dockerfile**: `/Dockerfile`  
**Base Image**: `node:20-bullseye-slim`  
**Configuration**:
- Installs Node.js 20, Git, Ruby, Ruby-dev, build-essential
- Installs Shopify CLI and theme-check via Ruby gems
- Exposes ports 3000 (Vite), 9292 (Shopify CLI)
- Working directory: `/workspace`

**Docker Compose Services**:
- **`node-dev`** - Main development container with volume mounts for source code and Shopify config
  - Ports: 3000 (Vite), 5173 (Vite alt), 9292 (Shopify)
  - Mounts: Current directory, ~/.config for Shopify CLI auth
  - User-based permissions via USER_ID and GROUP_ID env vars
- **`theme-check`** - Shopify theme linter service

**Usage**:
```bash
# One-time setup: Authenticate with Shopify on host
npx shopify theme list --store your-store.myshopify.com

# Start development
docker compose up node-dev
./scripts/docker/vite.sh    # Vite with HMR
./scripts/docker/dev.sh     # Shopify preview

# Run theme check
docker compose run --rm theme-check
```

## Main Files
**Entry Points**:
- `src/scripts/global.js` - Main JavaScript entry point (compiled to assets/global.js)
- `src/styles/tailwind.css` - Main CSS entry point

**Configuration Files**:
- `vite.config.js` - Vite build configuration with path aliases
- `tailwind.config.js` - Tailwind CSS content paths
- `postcss.config.js` - PostCSS plugins (Tailwind, Autoprefixer)
- `.env.example` - Environment variable template
- `config/settings_schema.json` - Theme settings schema
- `config/settings_data.json` - Theme settings data

**Core Components** (src/scripts/):
- `core/base-component.js` - Base class for Web Components
- `core/component-registry.js` - Auto-registration system
- `core/section-registry.js` - Shopify Section Rendering API integration
- `components/` - Web Components (mds-header-menu, mds-cart-drawer, mds-platform-slider, etc.)

**Layout Templates**:
- `layout/theme.liquid` - Main theme layout
- `layout/password.liquid` - Password-protected store layout

## Testing
**Framework**: Shopify Theme Check (Ruby-based linter)  
**Configuration**: `.theme-check.yml`  
**Run Command**:
```bash
# Local
npm run shopify:check

# Docker
docker compose run --rm theme-check
```

**Validation**: Uses Shopify Theme Check for Liquid template validation, best practices, and performance checks. No JavaScript unit testing framework currently configured.

## Multi-Store Architecture
**Store Configuration**: Each franchise store has config in `config/stores/{store-name}/`:
- `config.json` - Store metadata (storeName, storeUrl, displayName)
- `overrides/` - Store-specific customizations (settings, snippets, sections, assets)

**Deployment Script**: `scripts/deploy.js` orchestrates multi-store deployments using Shopify CLI.
